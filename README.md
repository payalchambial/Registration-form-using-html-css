Registration Form

About the Project

This project is a simple Registration Form developed using HTML and CSS. It allows users to enter their personal details through a clean and user-friendly interface.

Technologies Used

- HTML5
- CSS3

Features

- Name, mobile number, and email fields
- Gender selection
- Hobbies selection
- Course dropdown menu
- Submit and Reset buttons
- Simple and clean design

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.

Data Storage

Currently, this project is a front-end form only. The submitted data is not stored permanently. PHP and MySQL can be integrated in the future to process and store registration details.

Future Improvements

- Add PHP for form processing.
- Integrate MySQL for database storage.
- Add form validation and success messages.
